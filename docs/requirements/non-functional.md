# Нефункциональные требования к ПО «TaskPulse»

| ID | Категория | Измеримое требование |
| :--- | :--- | :--- |
| **NFR-01** | **Производительность** | Время отклика REST API на базовые CRUD-операции $\le 200$ мс при 95-м перцентиле (p95); полная загрузка и отрисовка Kanban-доски (до 100 тикетов) $\le 500$ мс. |
| **NFR-02** | **Безопасность** | Хэширование паролей алгоритмами Argon2id или bcrypt ($cost \ge 12$). Сессионные токены хранятся исключительно в защищенных HttpOnly, Secure, SameSite=Lax Cookie. |
| **NFR-03** | **Надёжность** | Целостность транзакций СУБД (ACID), автоматический перезапуск контейнеров в Docker (`restart: unless-stopped`) при непредвиденных сбоях. |
| **NFR-04** | **Usability (Удобство)** | Сетка 8pt, темная и светлая тема (Linear Dark/Light UI); интерактивное перемещение карточек в 1 действие Drag-and-Drop без перезагрузки веб-страницы. |
| **NFR-05** | **Совместимость** | Корректное отображение во всех современных браузерах на базе Chromium (Chrome, Edge 110+), Firefox 115+ и Safari 16+ на экранах от 1280×720 до 4K. |
| **NFR-06** | **Масштабируемость** | Поддержка одновременной работы до 50 активных разработчиков и ведение до 10 000 задач на проект без деградации времени ответа более чем на 15%. |
| **NFR-07** | **Сопровождаемость** | Модульная архитектура (Everything Claude Code: <800 строк на файл, функции <50 строк); покрытие доменной логики unit-тестами $\ge 80\%$ (факт: 99%). |
| **NFR-08** | **Ограничения среды** | Потребление оперативной памяти микросервисами $\le 512$ МБ RAM; запуск в Docker Compose одной командой `docker compose up -d` без внешних платных сервисов. |
| **NFR-09** | **Отказоустойчивость** | Автоматизированное создание ежедневных резервных копий (бэкапов) базы данных с возможностью полного восстановления состояния проекта не более чем за 5 минут. |
| **NFR-10** | **Аудируемость** | Ведение неизменяемого журнала аудита (Audit Trail) для всех операций смены статуса задач, удаления данных и смены прав с метками времени ISO 8601. |
