# Функциональные требования к ПО «TaskPulse»

| ID | Название | Описание действия системы | Роли пользователей |
| :--- | :--- | :--- | :--- |
| **FR-01** | Регистрация и профиль | Создание учетной записи с валидацией email, криптографическим хэшированием паролей и редактированием профиля. | Администратор, Тимлид, Разработчик |
| **FR-02** | Аутентификация и RBAC | Вход по логину/паролю с сессионными HttpOnly-куками и разграничением прав на уровне API для 4 ролей. | Все роли (Admin, Lead, Dev, Observer) |
| **FR-03** | Создание задач в бэклоге | Формирование тикета с заголовком, Markdown-описанием, типом, приоритетом, оценкой в часах и автогенерацией ключа `TP-XXX`. | Тимлид, Разработчик |
| **FR-04** | Декомпозиция тикетов | Редактирование атрибутов тикета, создание дочерних подзадач (Subtasks) и фиксация критериев Definition of Done. | Тимлид, Разработчик |
| **FR-05** | Интерактивный Kanban | Смена статусов карточек (Backlog -> To Do -> In Progress -> Code Review -> Done) через Drag-and-Drop с Optimistic UI. | Тимлид, Разработчик |
| **FR-06** | Диспетчеризация задач | Назначение ответственного исполнителя (Assignee) с контролем доступной недельной емкости часов. | Тимлид |
| **FR-07** | Учет трудозатрат | Списание фактически затраченного времени (Worklog) с пересчетом `spent_minutes` и остатка `remaining_minutes`. | Разработчик, Тимлид |
| **FR-08** | Управление спринтами | Формирование пула задач спринта, фиксация емкости (Capacity), целей (Sprint Goal), запуск и завершение итерации. | Тимлид |
| **FR-09** | Git Webhook интеграция | Прием входящих HTTP POST вебхуков Git, парсинг ключа задачи из коммита и автоматическая привязка хэша и ветки. | Внешний Git-сервер, Все роли |
| **FR-10** | Фильтрация и поиск | Многокритериальная фильтрация доски («Мои задачи», спринт, приоритет, статус) и полнотекстовый поиск тикетов. | Все роли |
| **FR-11** | Аналитика и Burndown | Построение графика сгорания задач (Sprint Burndown Chart) и сводного табеля трудозатрат (Timesheet) команды. | Все роли, Наблюдатель |
| **FR-12** | Контроль WIP-лимитов | Автоматическая проверка ограничений на число параллельных задач в колонках In Progress и Review с алертом о перегрузке. | Тимлид, Разработчик |
